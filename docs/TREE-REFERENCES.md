# Grenade tree references

## Request

Replace the tree's ordinary ornaments with UNSC frag grenades and Covenant plasma grenades. Plasma ornaments should glow. The user also wants an alternative to the star topper. The user approved the energy sword topper and grenade ornament plan. Both are implemented in the tree's inline SVG in `index.html`.

## Proposed art direction, not sourced facts

Draw simplified SVG ornaments consistent with the cabin rather than inserting photorealistic model cutouts. Keep frag bodies olive green with recognizable metal lever details. Use blue-purple plasma shells and cyan-white luminous details. Plasma glow should be soft and steady, not flashing. Preserve tree geometry, gifts and train layering.

The user chose an upright energy sword. The implemented tree has nine frag ornaments, nine steadily glowing plasma ornaments, and a split-blade sword topper. The original ornament anchor positions and tree geometry are preserved. The room regression suite checks the counts, SVG references, absence of ornament/topper animations, and decorative accessibility treatment, and captures the tree at desktop and phone sizes.
